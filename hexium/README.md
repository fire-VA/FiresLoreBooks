# FiresLoreBooks

Lore books you can place, read, collect and edit, and journals you write yourself.

- **Placed lore books** (Hammer → Furniture): tap E to read, hold E to take a copy (one per player per respawn; the book stays for everyone else), Shift+E to edit (admins).
- **Server text files**: books live in `BepInEx/config/FiresLoreBooks/Books/<id>.txt` on the server and can be edited outside the game; open readers refresh by themselves.
- **Rewards**: reading a book to its last page can grant quest steps, achievements, class XP, skills or attribute points, once per player (needs FiresRPGmaker / FiresRPGClasses).
- **Journal**: craft at the workbench; write entries, take pictures, lock it, or give it to a friend.
